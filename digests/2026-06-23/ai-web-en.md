### Research

**Agentic coding and persistent returns to expertise**
- **Published:** 2026-06-22 (research blog) | **Full paper date:** Jun 16, 2026
- **Link:** https://www.anthropic.com/research/claude-code-expertise

This is a landmark empirical study analyzing ~400,000 Claude Code sessions from October 2025 to April 2026. The research introduces a framework for studying interactive agentic coding while preserving user privacy. **Core findings:**

1. **Division of labor:** Humans retain planning decisions ("what to do") while Claude handles most execution decisions ("how to do it"). The greater the user's domain expertise, the more execution work Claude performs per instruction.

2. **Success rates across occupations:** Every major occupation succeeds on coding tasks at nearly the same rate as software engineers — a striking finding suggesting Claude Code broadly democratizes basic coding competence. However, expert users still achieve higher success rates, though the gap between intermediate and expert is "modest."

3. **Behavioral shifts over 7 months:** The share of sessions spent debugging fell by nearly half. Usage shifted toward end-to-end agentic work — deploying and running code, analyzing data, and writing non-code documents. This suggests Claude is moving from a coding assistant to a general-purpose agentic tool.

4. **Rising task value:** Estimated task value (benchmarked against freelance job postings) rose ~25% on average across almost all work categories, indicating users are trusting Claude with increasingly complex and valuable assignments.

**Strategic significance:** This is among the first large-scale, privacy-preserving empirical analyses of real-world agentic coding usage. It provides quantitative evidence that the value of AI coding tools is not just in speed but in enabling entirely new categories of work. The finding that expertise persistently compounds returns has direct implications for enterprise deployment strategy — organizations should invest in domain training for users to maximize AI ROI.
